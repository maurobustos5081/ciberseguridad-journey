##### 🔹 Apuntes clave del Módulo 4 (Ingeniería Social):
* **Concepto clave:** Explotación del factor humano mediante la manipulación psicológica, pretexto y abuso de confianza.
* **Vectores de ataque principales:**
  * **Phishing, Vishing y Smishing:** Suplantación de identidad por email, llamadas telefónicas y SMS respectivamente.
  * **Baiting / USB Dropping:** Uso de medios físicos infectados para comprometer redes corporativas.
  * **Watering Hole:** Compromiso de sitios web frecuentados por el objetivo para infectar a sus usuarios.
  * **Pivoting:** Técnica para utilizar un equipo o cuenta comprometida mediante ingeniería social como puente para escalar acceso en la red interna.
